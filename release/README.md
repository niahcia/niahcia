# Release Support Files

This directory contains templates and examples used to publish NIAHCIA releases.

Files:

- `RELEASE_NOTES_TEMPLATE.md` — release-note structure
- `release-manifest.example.json` — machine-readable release manifest example
- `SHA256SUMS.example` — checksum file format example

These are templates only. Real generated release artifacts belong on the GitHub Release, not committed back into the repository.
